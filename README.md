# آزمون‌فا | Azmoon Fa

رابط فارسی و نصب‌کننده TCExam، با طراحی و شخصی‌سازی howard-99.

[![آزمون نصب و مرورگر](https://github.com/howard-99/azmoon-fa/actions/workflows/verify.yml/badge.svg)](https://github.com/howard-99/azmoon-fa/actions/workflows/verify.yml)

آزمون‌فا موتور آزمون رسمی را در هر **نصب تازه** از آخرین تگ پایدار گیت‌هاب دریافت می‌کند. نام و نام کوتاه مؤسسه از شما پرسیده می‌شود؛ هویت مؤسسه در قالب ثبت نشده و پس از نصب از پنل مدیر قابل تغییر است.

## نصب آسان

روی **Ubuntu Server 24.04 تازه**، با دسترسی sudo و اینترنت:

```bash
sudo apt-get update && sudo apt-get install -y git
git clone https://github.com/howard-99/azmoon-fa.git
cd azmoon-fa
sudo bash install.sh
```

نصب‌کننده نام کوتاه، نام کامل، آدرس سامانه، شبکه مجاز، نام مدیر و رمز جدید را می‌پرسد. برای HTTPS باید گواهی و کلید موجود سرور را معرفی کنید. در پایان، لینک ورود کاربران، پنل مدیر، تنظیمات مؤسسه و کارنامه‌ها نشان داده می‌شوند.

| امکان | رفتار |
|---|---|
| فارسی و راست‌به‌چپ | پنل کاربران و مدیریت؛ فونت محلی بدون اتصال به سرویس فونت |
| محیط آزمون | شمارش معکوس رسمی، راهنمای ثبت، پیمایش سؤال‌ها و نمایش مناسب موبایل |
| کارنامه | نمره، وضعیت قبولی، پاسخ انتخاب‌شده، پاسخ صحیح، توضیح و وضعیت تصحیح |
| چاپ و PDF | چاپ مرورگر / ذخیره PDF و دریافت PDF بومی با متن فارسی |
| هویت مؤسسه | نام، نام کوتاه و رنگ اصلی؛ ویرایش توسط مدیر |
| نصب قابل بررسی | کنترل سازگاری قبل از ساخت پایگاه داده؛ گزارش نسخه و commit رسمی |
| نگهداری | بررسی سلامت و پشتیبان کامل با دسترسی محدود |

جزئیات پاسخ درست فقط زمانی نمایش داده می‌شود که مدیر **نمایش نتیجه** و **نمایش گزارش به کاربر** را در تنظیمات آزمون فعال کرده باشد. سؤال تشریحی تا زمان تصحیح مدرس، نمره نهایی ندارد. ثبت پاسخ مانند موتور رسمی، با «ثبت پاسخ» یا رفتن به سؤال بعد انجام می‌شود.

## بعد از نصب

- کاربران: `آدرس‌سامانه/public/code/`
- مدیر: `آدرس‌سامانه/admin/code/`
- هویت مؤسسه: `آدرس‌سامانه/admin/code/azmoon_settings.php`
- کارنامه‌ها: `آدرس‌سامانه/public/code/tce_test_allresults.php`
- رسید نصب و لینک‌ها: `/var/lib/azmoon-fa/access.txt`؛ فقط مدیر سرور می‌تواند آن را بخواند.

رمز مدیر، همان رمز واردشده هنگام نصب است؛ رمز پیش‌فرض آماده‌ای منتشر نمی‌شود. کاربران و گروه‌ها را از پنل مدیر ایجاد کنید و گروه مناسب را به آزمون اختصاص دهید. ثبت‌نام عمومی و بازیابی رمز با ایمیل به‌صورت پیش‌فرض خاموش هستند؛ راه‌اندازی ایمیل به تنظیم SMTP و تغییر تنظیمات موتور نیاز دارد.

```bash
sudo bash doctor.sh
sudo bash backup.sh
```

## محدوده پشتیبانی

این نسخه برای نصب تازه است. اجرای مجدد روی سامانه موجود متوقف می‌شود تا آزمون‌ها و کاربران بازنویسی نشوند. ارتقای سامانه موجود باید ابتدا در کپی آزمایشی و با پشتیبان انجام شود. اگر نسخه آینده TCExam قرارداد قالب یا کلیدهای ترجمه را تغییر دهد، نصب قبل از ساخت پایگاه داده متوقف می‌شود؛ نیاز به به‌روزرسانی آداپتور خواهد داشت.
